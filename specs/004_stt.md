# 004 STT

## Purpose

Specify speech-to-text boundaries for the MVP while avoiding mandatory heavyweight model dependencies.

## Requirements

- Define a speech-to-text backend interface.
- Provide a mock backend for deterministic tests and demos.
- Add a placeholder backend for future `whisper.cpp` or `faster-whisper` integration.
- Do not require Whisper to run tests or mock mode.

## Non-goals

- No model download automation.
- No streaming transcription.
- No speaker identification.

## Interfaces

- `SpeechToTextBackend.transcribe(frames: Sequence[AudioFrame]) -> Transcription`
- `Transcription(text, confidence, backend)`
- `MockSTTBackend(transcript)`
- `WhisperBackend(model_name)`

## Acceptance criteria

- Mock backend returns configured text.
- Placeholder backend fails with a clear `NotImplementedError`.
- Router receives plain transcript text.

## Test cases

- Full mock pipeline uses `MockSTTBackend`.
- Empty transcript routes to safe fallback.

## Open questions

- Should the first real backend be `faster-whisper` or `whisper.cpp`?
- How should model paths be configured?
